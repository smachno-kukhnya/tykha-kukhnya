# Тиха кухня

Статичний сайт із колекцією українських рецептів. У проєкті немає серверної частини, збірки, фреймворків і зовнішніх JavaScript-бібліотек.

## Запуск

Відкрийте `index.html` у сучасному браузері — локальний сервер не потрібен. HTML, стилі, сценарії та дані рецептів завантажуються з файлів проєкту. Для фотографій і шрифтів потрібне підключення до інтернету; кожне фото має резервне зображення, а картки зберігають місце з кольоровим фоном, якщо джерело недоступне.

## Можливості

- Каталог із 50 рецептів у п’яти категоріях із пошуком за назвою та інгредієнтами, комбінованими фільтрами й сортуванням.
- Категорії, обране, сторінки «Про проєкт» і «Контакти».
- Докладні рецепти з інгредієнтами, покроковим приготуванням, калорійністю та перерахунком порцій.
- Світла й темна теми; тема та обране зберігаються в `localStorage` цього браузера.
- Друк рецепта.
- Форма контактів перевіряє поля на пристрої. Вона не надсилає дані: скопіюйте сформоване повідомлення та надішліть його самостійно.

## Файли

- `index.html` — розмітка та розділи сайту.
- `styles.css` — адаптивні стилі й теми.
- `recipes.js` — основний набір рецептів.
- `recipes-extra.js` — додаткові рецепти для категорій.
- `app.js` — навігація й інтерактивна поведінка.
